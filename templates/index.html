LOMPAT!

Filter kamera berbasis computer vision untuk permainan lompat tradisional Indonesia, bisa dimainkan beramai-ramai (hingga 6 orang). Berdiri di depan kamera, sistem mendeteksi kaki dan badan setiap pemain. Melompatlah saat objek virtual lewat: lolos = skor +1, kena = nyawa −1.

Tips kamera: taruh laptop/HP rendah, mundur ±2–4 meter sampai seluruh badan sampai kaki semua pemain terlihat, beri jarak antarpemain, dan pastikan ruangan terang. Pemain baru boleh masuk frame kapan saja. Mode demo: tap layar (atau tekan Spasi di laptop) untuk melompat sebagai P1.

Teknologi: MediaPipe Pose Landmarker (33 titik tubuh per orang, hingga 6 orang). Server Flask: frame kamera diproses Python di laptop ini (pelacakan pemain & penilaian lompatan juga di server). Browser: cadangan, semua diproses di browser tanpa server.
